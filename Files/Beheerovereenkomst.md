# Beheerovereenkomst — vervallen document

Dit bestand is **niet langer** het template voor de juridische managed-services-overeenkomst.

De inhoud is gesplitst en uitgewerkt in:

| Rol | Bestand |
| --- | --- |
| Hoofdcontract | `Juridisch_Contract_Managed_Services.md` |
| Bijlage A — Scope | `Bijlage_Scope_Managed_Services.md` |
| Bijlage B — SLA | `SLA_Standaard.md` |
| Bijlage C — URLs / infra | `Bijlage_C_Componenten_URLs_en_infrastructuur.md` |
| Bijlage D — Prijs | `Bijlage_D_Prijs_en_facturatie.md` |
| Uitleg documentstructuur | `Documentstructuur_Managed_Services.md` |

Gebruik deze bestanden voor nieuwe en gewijzigde afspraken. Verwijs in correspondentie niet meer naar “de Beheerovereenkomst” als apart contractdocument tenzij u doelt op **historische** dossiers die nog op het oude model zijn gebaseerd.
